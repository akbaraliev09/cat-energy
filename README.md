# Cat Energy

Учебный лендинг «Функциональное питание для котов» по макету.
React + Vite, три раскладки: десктоп (от 1200px), планшет (768–1199px), мобильная (до 767px).

## Как запустить

```
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:5173

## ВАЖНО: куда класть фотографии

Все картинки кладутся в папку **`public/img/`** под точными именами из таблицы.
Пока файла нет, на сайте виден пунктирный серый блок с подписью, какой файл туда положить.
Все пути записаны в одном месте: **`src/images.js`** (если у вас jpg вместо png, поменяйте расширение там).

| Файл | Что это | Формат |
|---|---|---|
| `logo.png` | Логотип: лиса в жёлтом круге (шапка и метка на карте) | PNG/SVG, прозрачный фон |
| `hero-cat.jpg` | Фото кота для зелёного фона первого экрана | JPG |
| `jar.png` | Банка корма Cat Energy Pro, наклонённая, с тенью | PNG, **прозрачный фон** |
| `icon-slim.png` | Чёрный силуэт сидящего кота («Похудение») | PNG, прозрачный фон |
| `icon-pro.png` | Чёрный силуэт пантеры («Набор массы») | PNG, прозрачный фон |
| `cat-before.png` | Кот «Было» (полный) | PNG, прозрачный фон |
| `cat-after.png` | Кот «Стало» (стройный), **тот же размер и поза**, что и «Было» | PNG, прозрачный фон |
| `map.jpg` | Карта для блока «Приглашаем к сотрудничеству дилеров» | JPG |

Совет: картинки экспортируйте из макета (Figma) в размере x2 для чёткости.
Иконки шагов (листок, миска, вилка, будильник) и соцсети нарисованы кодом, файлы для них не нужны.

## Структура

```
src/
  images.js            пути ко всем фото
  App.jsx              страница собирается из блоков
  styles.css           стили (мобильная версия → планшет → десктоп)
  components/
    Header.jsx         шапка, меню, бургер
    Hero.jsx           первый экран
    Programs.jsx       карточки «Похудение» и «Набор массы»
    HowItWorks.jsx     4 шага
    Example.jsx        «Живой пример» со слайдером Было/Стало
    Dealers.jsx        карта и адрес
    Footer.jsx         подвал
    Photo.jsx          картинка + серая подсказка, если файла нет
    Icons.jsx          иконки (SVG)
```
